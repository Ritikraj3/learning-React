📘 Why Do We Need React? – Learning React Series

Welcome to the first step in the journey of mastering React!
This project demonstrates why React is needed by comparing traditional HTML/JavaScript DOM manipulation with the React way of building dynamic UIs.

> ✨ This is part of my Learning React series, where I explore React fundamentals in a progressive manner.




---

📌 Objective

Before diving into React, it's important to understand:

The limitations of vanilla JavaScript for building interactive UIs.

The benefits of using a library like React for managing dynamic content.


This project answers:

> Why choose React over plain JavaScript?




---

🔍 What You'll Learn

How the traditional DOM works (imperative programming).

The problems that arise when UI grows in complexity.

How React simplifies UI logic with declarative syntax.

Real-world comparison: DOM vs React in updating the UI.



---

📂 Project Structure

01_Why-do-we-need-React/
│
├── index.html          # Traditional HTML & JS UI (Vanilla)
├── react.html          # Same UI recreated with React
├── script.js           # JS logic for DOM manipulation (Vanilla)
├── react.js            # React-based UI rendering
└── README.md           # 📘 You are here


---

🧪 How to Run

1. Clone the Repo

git clone https://github.com/Ritikraj3/learning-React.git
cd learning-React/01_Why-do-we-need-React

2. Open Files

Just open index.html and react.html in your browser to compare:

index.html – Uses traditional DOM manipulation.

react.html – Uses React to render and update UI.


No additional setup is needed.

---

✅ Key Takeaways

Imperative vs Declarative: React abstracts DOM manipulation with a cleaner, declarative style.

Component-based: UI can be split into smaller, reusable components.

Faster updates: React handles DOM updates efficiently using its Virtual DOM.
